# LetsStay

LetsStay is a web application project for homestay and eco-tourism businesses.

Developed as part of the TBI SIP 2026 Internship Program.

## Objective

To help homestay owners manage bookings and analyze guest feedback using AI-assisted features.

## Tech Stack

* React JS
* Node.js + Express.js
* PostgreSQL (Supabase)
* Tailwind CSS
* React Router

## Features Implemented (Week 2)

* Responsive Navbar
* Hero Section
* Reusable Card Component
* Footer Component
* React Router Setup
* Home, About, Login, and Dashboard Pages

## Planned Features

* User Authentication
* Homestay Listings
* Booking Management
* Guest Reviews
* AI-assisted Review Analysis

## Status

Frontend initialized with React + Vite, Tailwind CSS configured, core UI components created, and page routing implemented.
