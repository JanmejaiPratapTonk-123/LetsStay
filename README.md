# LetsStay

LetsStay is a web application project for homestay and eco-tourism businesses.

Developed as part of the TBI SIP 2026 Internship Program.

## Objective
To help homestay owners manage bookings and analyze guest feedback using AI-assisted features.

## Tech Stack
- React JS
- Node.js + Express.js
- PostgreSQL (Supabase)

## Planned Features
- User Authentication
- Homestay Listings
- Booking Management
- Guest Reviews
- AI-assisted Review Analysis

## Status
Project is currently in the initialization and planning phase.
